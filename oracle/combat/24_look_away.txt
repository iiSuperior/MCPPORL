# Clicking while facing away from B (in reach) is a whiff: the server would
# accept the hit, but the client's crosshair pick finds nothing. Releasing the
# key clears the whiff lockout, so flicking back and clicking 2 ticks later hits.
start A x=0.5 z=0.5 yaw=0
start B x=0.5 z=3.0 yaw=180
20 idle | idle
1 attack yaw=180 | idle
1 idle yaw=0 | idle
1 attack | idle
30 idle | idle
